# Ogun Poetry Festival

The website of the Ogun Poetry Festival, *Creativity for Humanity*.
2026 edition: **Artistic Expression for Advocacy**, Saturday 5 December 2026,
Cinema Hall, June 12 Cultural Centre, Abeokuta.

```bash
npm install
npm run dev        # http://localhost:8080
npm run typecheck
npm run build
```

See [`CLAUDE.md`](CLAUDE.md) for the design system, writing rules and what to
build next, and [`docs/brief.md`](docs/brief.md) for the source content.
